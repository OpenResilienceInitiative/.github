# Contributing to ORISO

The contribution guide for all ORISO repositories lives in ORISO-Docs:
**[ORISO-Docs/CONTRIBUTING.md](https://github.com/OpenResilienceInitiative/ORISO-Docs/blob/dev/CONTRIBUTING.md)**

It covers how to propose a feature or a small fix, when a change needs an ADR, and how issues,
branches and pull requests work, for the core team and external contributors alike.
